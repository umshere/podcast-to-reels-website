# Podcast to Reels

A web application that automatically converts podcast episodes into engaging short-form video reels for social media platforms.

## Live Demo

Visit the live demo at [https://eysfarig.manus.space](https://eysfarig.manus.space)

## Project Overview

This project offers an efficient solution for content creators to transform long-form podcast content into bite-sized, visually appealing video clips suitable for platforms like Instagram Reels, TikTok, and YouTube Shorts. Using AI and automation, it extracts key moments from podcasts and generates engaging short videos with minimal manual intervention.

## Features

- Podcast episode upload and processing
- AI-powered content summarization and highlight extraction
- Customizable visual templates for social media platforms
- Automatic subtitle generation
- Background music and visual effects
- Batch export capabilities for multiple platforms
- User-friendly interface built with React and Tailwind CSS

## Tech Stack

- **Frontend**: React, TypeScript, Tailwind CSS, Shadcn UI
- **Build**: Vite
- **Styling**: Tailwind CSS
- **Deployment**: Custom deployment at eysfarig.manus.space

## Getting Started

### Prerequisites

- Node.js 16+
- npm or yarn

### Installation

1. Clone the repository:

   ```
   git clone https://github.com/umshere/podcast-to-reels-website.git
   cd podcast-to-reels-website
   ```

2. Install dependencies:

   ```
   npm install
   # or
   yarn install
   ```

3. Start the development server:

   ```
   npm run dev
   # or
   yarn dev
   ```

4. Open your browser and navigate to `http://localhost:5173`

## Build for Production

```
npm run build
# or
yarn build
```
